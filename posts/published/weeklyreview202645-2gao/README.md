# WeeklyReview#202645

# Coding

[**How to Prepare a Flutter App for Google Play Closed Testing**](https://forum.itsallwidgets.com/t/how-to-prepare-a-flutter-app-for-google-play-closed-testing/4942): a checklist to publish a flutter app to google play.

[**Benchmark: Which Dart loop is the fastest?**](https://filiph.net/text/dart-for-loops-performance.html): a microbenchmark on loop performance in Dart. Conclusion: in most case ,the compiler is smart enough to optimize loops, even when using `forEach()`.

[**What Every C Programmer Should Know About Undefined Behavior #1/3**](https://blog.llvm.org/2011/05/what-every-c-programmer-should-know.html)

[**Unicode, Tolkien, and Privacy**](https://www.johndcook.com/blog/2025/03/09/tengwar/)

[**Bondy-connect**](https://github.com/bondy-io/bondy-connect/releases/tag/1.0.1): first 1.0.0 and 1.0.1 release of bondy-connect.

[**Pattern-Oriented-Software-Design**](https://github.com/forlo581230/Pattern-Oriented-Software-Design): a Prolog term matching program.

[**Prolog for Pattern-Oriented Software Diagnostics**](https://www.dumpanalysis.org/files/Prolog_for_Pattern-Oriented_Software_Diagnostics_V20.pdf)

# System

[**AlpineBSD**](https://wiki.alpinebsd.org/):  operating system based on the NetBSD kernel with a userspace inspired by Alpine Linux and the objective of making it possible to use as little AI-generated software as possible. There is no LLM output included in the base system or main package repository (AlpineBSD AI policy).

[**Linux First Patch**](https://kernelnewbies.org/FirstKernelPatch): A checklist to create your first Linux patch.

[**safeL4: Rethinking Safe-Language-Based Single Address Space Microkernels**](https://arxiv.org/pdf/2610.35999)

[**kmorph**](https://github.com/multikernel/kmorph): transforms a running multikernel Linux machine from one kernel into another without a reboot. A second kernel, the successor, is armed beside the kernel running the machine, the predecessor, and takes it over.

# Database

[**HypoPG**](https://github.com/HypoPG/hypopg): hypothetical -- or virtual -- index is an index that doesn't really exist, and thus doesn't cost CPU, disk or any resource to create. They're useful to know if specific indexes can increase performance for problematic queries

# Security

[**Trezor says a tampered wallet came from the reseller tied to the Ledger thefts. How do you check yours?**](https://www.msn.com/en-us/technology/cryptocurrencies/trezor-says-a-tampered-wallet-came-from-the-reseller-tied-to-the-ledger-thefts-how-do-you-check-yours/ar-AA2grb5H): don't. trust. startups. They don't respect elementary security rules, that's why their products are usually cheap. If the manufacturing chain has been compromised, all their products are just garbage. Like few crypto-bros are saying, if you want a wallet/ledger, use a very old air-gapped laptop.

[**Lenovo's 'encrypted' fingerprint USB drive is just an unencrypted SD card in a fancy case — AI-assisted follow-up finds a backdoor and hardcoded keys in other ‘secure’ USB products**](https://www.tomshardware.com/tech-industry/cyber-security/lenovo-fingerprint-usb-stick-sold-as-aes-256-encrypted-had-a-plain-sd-card-inside-ai-assisted-follow-up-finds-a-backdoor-and-hardcoded-keys-in-other-secure-usb-products)

[**POWBlock**](https://github.com/8Protons/POWBlock): high-performance, zero-dependency, system/stack-agnostic Proof of Work microservice that turns any proxy or server into a defense gate against AI scrapers, bots, and DDoS attacks.

[**DOPPLERGEIST**](https://github.com/1337isnot1337/DOPPLERGEIST): a Python tool for acoustic geolocation research. It analyzes aircraft Doppler patterns in audio recordings and compares them against historical ADS-B flight trajectories to estimate possible recording locations.
