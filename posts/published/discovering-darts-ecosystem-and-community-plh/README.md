# Discovering Dart Ecosystem and Community

Like any language, having a list of resources to find examples and best practices is always nice to have. Unfortunately, Dart is mostly used for/with Flutter, and lot of publications are directly showing Flutter examples instead of talking about Dart itself. Anyway, this not a complete list, only the things I've found on the web and started to check.

- [**Official Dart Website**](https://dart.dev/): this is the main entry-point for any Dart developpers, from beginners to advanced.

- [**Official Dart Tutorials**](https://dart.dev/learn): First time using Dart? That's the place to be.

- [**Official Dart documentation**](https://dart.dev/docs): If something goes wrong, or if you want to know what a class, method or attribute is doing, this is the best place.

- [**Official Dart Announcement on Google Group**](https://groups.google.com/a/dartlang.org/g/announce): all important news regarding Dart are published here, useful for the new releases and other critical information about the language.

- [**Official Dart Blog**](https://dart.dev/blog): One can found many interesting information about the language and the community.

- [**Official Dart Package Website**](https://pub.dev/): the first place to check if you want to use a specific feature and you don't have time to create it from scratch.

- [**Official Dart API documentation**](https://api.dart.dev/): wants to know more about Dart API and SDK? you'll probably find your answer here.

- [**Official Dart Language Specification**](http://dart.dev/resources/language/spec): Dart Language has been specified, and the syntax and other rules have been documented.

- [**Effective Dart**](https://dart.dev/effective-dart) (Official Dart Best Practices): the official best practice guide from Dart developers.

- [**Official List of Companies using Dart**](https://dart.dev/community/who-uses-dart): Want to work with Dart (or Flutter), this page can give you some hints about which companies are using this language in production.

# Sources

Having access to open-source projects and official source code is always useful. If you want to learn Dart, you should start by reading the tests and then try to understand the code tested.

- [**Official Dart Github Profile**](https://github.com/dart-lang): the page listing all official project supported by Dart.

- [**Official Dart SDK Repository**](https://github.com/dart-lang/sdk): Dart SDK source code.

- [**Official Dart Language Specification Repository**](https://github.com/dart-lang/language): Dart language specification source code

# Interesting Packages

A long list of packages had my attention while I was learning Dart/Flutter, and while I was reading books/publications. Here few of them

- [**actors**](https://pub.dev/packages/actors): an implementation of the Actor Model in Dart.

- [**beam_vm**](https://pub.dev/packages/beam_vm): a plugin to embed an Erlang VM on Android and iOS.

- [**cryptography**](https://pub.dev/packages/cryptography): cryptographic algorithms implemented in Dart.

- [**dart_amqp**](https://pub.dev/packages/dart_amqp): AMQP implementation in Dart.

- [**cbor**](https://pub.dev/packages/cbor): an implementation of [CBOR/RFC8949](https://www.rfc-editor.org/rfc/rfc8949.html) in Dart.

- [**dartzmq**](https://pub.dev/packages/dartzmq): an implementation of [zeromq](https://zeromq.org/) in Dart.

- [**dio**](https://pub.dev/packages/dio): an advanced HTTP networking tool.

- [**drift**](https://pub.dev/packages/drift): a persistent storage layer using SQLite.

- [**ecdsa**](https://pub.dev/packages/ecdsa): an implementation of ECDSA.

- [**ed25519_edwards**](https://pub.dev/packages/ed25519_edwards): an implementation of ed25519 elliptic curve.

- [**flame**](https://pub.dev/packages/flame): a game engine based on dart/flutter.

- [**fpdart**](https://pub.dev/packages/fpdart) ([github](https://github.com/SandroMaglione/fpdart)):  Functional Programming in Dart.

- [**oauth2**](https://pub.dev/packages/oauth2): an OAuth2 client.

- [**postgres**](https://pub.dev/packages/postgres): an interface to PostgreSQL database.

- [**pure**](https://pub.dev/packages/pure): add support for many functional programming features, like composition, pipes, memoization and recursion.

- [**sqlite3**](https://pub.dev/packages/sqlite3): an interface to sqlite3 database.

- [**state_machine**](https://pub.dev/packages/state_machine): Implementation of a finite state machine in Dart.
