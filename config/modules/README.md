# Publish Modules

`publish` offers modules to help dealing with extra tasks
when publishing contents. 

- `wayback_machine`: archive the post on the wayback machine after the final publication;

- `archive_today`: archive the post on archive.today website;

- `gist`: publish a formatted txt version of the post on gist.github.com;

- `humans`: create a `humans.txt` file at the root of the publication directory;

- `robots`: creates a `robots.txt` file at the root of the publication directory;

- `atom`: add atom feed support

- `rss`: add rss feed support

- `map`: add a `sitemap.xml` file
